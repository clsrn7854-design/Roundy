# Roundy

> 오늘 뛰기 좋은 우리 동네 한 바퀴

Roundy는 출발지와 원하는 거리만 정하면 **출발지로 돌아오는 러닝 코스**를 만들어 추천하는 반응형 웹 서비스입니다. 날씨와 대기질로 오늘 뛰기 좋은지도 함께 알려줍니다.
MVP는 **서울 송파구**를 대상으로 하고, 이후 마포구로 넓힐 예정입니다.

> 현재 상태: 기획을 마치고 개발을 준비하고 있습니다. 실행 방법과 화면은 개발하면서 채웁니다.

## 왜 만들었나

| 문제 | Roundy의 해결 |
|---|---|
| 뛰기 전에 날씨, 미세먼지, 지도, 편의시설을 앱마다 따로 확인해야 함 | 러닝 지수, 순환 코스, 주변 화장실을 한 화면에 제공 |
| "5km, 평지, 출발한 곳으로 돌아오는 코스"처럼 조건에 맞는 코스를 찾기 어려움 | 출발지와 거리만 정하면 길 그래프로 순환 코스 생성 |
| 공식 코스는 장거리 여행길 위주라 동네 코스 정보가 부족함 | 공원과 강변 길을 우선하는 동네 코스 생성 |

MVP가 답해야 할 질문은 세 가지입니다.

1. 실제 길 데이터로 출발지에 돌아오는 순환 코스를 만들 수 있는가
2. 만든 코스가 원하는 거리와 조건(평지, 공원·강변, 화장실)을 만족하는가
3. 날씨와 대기질을 근거로 오늘 뛸지 판단할 수 있는가

## 주요 기능 (MVP)

- **오늘의 러닝 컨디션**: 날씨와 미세먼지를 0~100점 러닝 지수로 보여주고, 위험한 날에는 실내 운동을 권장
- **순환 코스 추천**: 출발지와 거리를 정하면 돌아오는 코스를 최대 3개 생성. 공원·강변 길 우선, 평지와 화장실 조건 선택
- **자연어 검색**: "퇴근 후 5km 평지 화장실 있는 곳"을 검색 조건으로 변환하고, 실제 데이터로만 추천 이유를 설명
- **코스 상세와 저장**: 지도 경로, 거리, 고도차, 예상 시간, 데이터 출처, 즐겨찾기
- **자주 쓰는 출발지**: 집, 회사 같은 장소를 저장해 한 번에 선택

코스 검색과 추천은 로그인 없이 쓸 수 있고, 저장 기능만 로그인이 필요합니다.

## 기술 스택

| 구분 | 기술 | 역할 |
|---|---|---|
| 프론트엔드 | React | 반응형 화면, 카카오맵 JavaScript SDK |
| 백엔드 | FastAPI | API 서버, 외부 API 비동기 호출 |
| 메인 DB | PostgreSQL + PostGIS | 회원, 코스, 공원, 화장실, LLM 로그(JSONB) |
| 그래프 DB | Neo4j | 보행로 그래프, 순환 코스 탐색 |
| 캐시 | Redis | 날씨, 대기질, 기상특보 응답 캐시 |
| AI | LangChain + Claude API | 자연어를 검색 조건으로 변환, 추천 이유 생성 |
| 인프라 | Docker, AWS EC2, GitHub Actions | 개발 환경, 배포, CI/CD |

일부 기술은 1주차 검증 결과에 따라 바뀔 수 있습니다.
- Neo4j로 시제품을 만들다 막히면 PostGIS + pgRouting으로 전환합니다.
- LLM은 Claude Haiku 5.5로 시작하고, 6주차에 OpenAI GPT-6 Luna와 비교해 확정합니다.

## 아키텍처

```
[React 웹] ──HTTPS·JSON──▶ [FastAPI 서버 · AWS EC2 (Docker)] ──▶ 외부 API
                                │                                  (기상청, 에어코리아,
                                │                                   카카오 로컬, Claude API)
              ┌─────────────────┼─────────────────┐
              ▼                 ▼                 ▼
         PostgreSQL           Neo4j             Redis
```

브라우저는 FastAPI만 호출하고, 외부 API 호출과 DB 접근은 모두 FastAPI가 맡습니다.

## 폴더 구조 (예정)

```
Roundy/
├── frontend/   # React 앱
├── backend/    # FastAPI 서버
├── data/       # 데이터 수집·전처리·적재 스크립트 (원본 데이터 파일은 올리지 않음)
└── docs/       # 기획서와 설계 문서
```

## 시작하기

개발을 시작하면 채웁니다.

- 필요한 환경 변수는 `.env.example`에 정리합니다. 실제 키는 `.env`에만 두고 Git에 올리지 않습니다.
- 로컬에서는 Docker Compose로 FastAPI, PostgreSQL, Neo4j, Redis를 함께 띄울 예정입니다.

## 데이터 출처

| 데이터 | 출처 | 용도 |
|---|---|---|
| 보행로 네트워크 | [OpenStreetMap](https://www.openstreetmap.org/) | 순환 코스 생성용 길 그래프 |
| 고도 | Copernicus DEM (30m) | 고도차, 평지 판별 |
| 공원 | 공공데이터포털 전국도시공원정보표준데이터 | 공원 위치, 공원 길 판별 |
| 공중화장실 | 공공데이터포털 전국공중화장실표준데이터 | 코스 주변 편의시설 |
| 날씨, 기상특보 | 기상청 단기예보·초단기실황·기상특보 API | 러닝 지수 |
| 대기질 | 한국환경공단 에어코리아 API | 러닝 지수 |
| 공식 코스 (확장) | 한국관광공사 두루누비 API | 장거리 공식 코스 |
| 장소 검색, 지도 | 카카오 로컬 API, 카카오맵 | 출발지 검색, 지도 표시 |

- 지도 데이터 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 라이선스
- 공공데이터의 이용허락범위(공공누리 유형)는 API를 신청할 때 확인해 이 표에 추가합니다.
- 합성 데이터는 사용하지 않습니다.
